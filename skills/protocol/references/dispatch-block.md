# 派单模板(整块照抄进派单,逐项填空;留空 = 派单不合格)

先跑 `flow-dispatch <任务号> --tree <快照|活树-独占|禁入> --db <独占|只读|禁用> --seq <N> --round <轮名> --dir <流程目录绝对路径> [--core <核心库写权限>] [--plan <plan 绝对路径>] [--cap-ok <理由>] <触面路径(仓库相对)…> > <流程目录>/<轮号>-dispatch.md`(如 `01-dispatch.md` / `02a-dispatch.md`),Edit 补「(待填)」行,再 `flow-round open <流程目录> <轮名>`;派单 = 这个文件,Agent prompt 只给它的路径(末段三行)。
生成段自带:plan 任务节选(①写正文封顶,②③④ 只 outline + REQ 行)· 门名 · flow-ev 与门的命令连实参 · 必读骨架(上一轮回件 · flow-local · 账本行区间)· 回件模板全文(`flow:tpl` 段)· ①写 的步骤账 `.steps-①写.md`。
中断后 `flow-dispatch --resume <原派单> --dir <流程目录> > <轮号>b-dispatch.md`(①写 从步骤账、②③④ 从回件已落的节生成接手点),不手写续轮派单。下面这块是它输出的骨架。

```
## 〇 · 派单必带块

- 树权限:快照(哈希可证) / 活树-独占 / 禁入      ← 三选一,只读 agent 一律快照
- 库权限:独占 / 只读(不许重置库) / 禁用           ← 三选一;任何时刻只许一个持有者跑重置
- git 权限:零 git 写(HEAD 必须 <hash>);porcelain 起点 <N>,允不允许变大:<是/否>
- 写权限面:许写 = 触面(flow-dispatch 从同一组触面参数印出,与 .face-<轮名>.txt 同源;close 判 本轮〇表路径 ⊆ 面,越面 RED,例外走〇表「例外」列 `裁决-N`)
    禁写:<逐条写明,别写「其余不许」>(待填)
    改轮必答:能不能写核心库?——「只许 shell」或「核心库限 <具体文件 / 性质>」
- 裁决号段:从 N 起(并行支各给段,防撞号;开工先核上一轮最大号 < N)
- 门:(flow-dispatch 从 config flow_gates 印名单)
- 回件模板:(flow-dispatch 按 --round 整块印进 flow:tpl 段)
- 判据命令一律经 flow-ev:(flow-dispatch 印连实参的写法;全量落 .evidence/<轮名>-<名>.txt,账记 .evidence/<轮名>-log.tsv)
- 收工件只有回件:申报清单 = 回件〇表第二列路径;冻结 · verify(含测试锁)· 假话门 · 越面 · 预算 全由编排方 flow-round close 跑
    独占轮另跑一次门整跑 `flow-ev … gates -- flow-gates --reset`;快照轮开工与收工各对上一轮 .after 跑一次 shasum -c(证副本同构,别人证不了)
- 必读:(flow-dispatch 印骨架:上一轮回件按首行认领 · flow-local · 账本行区间;手写段只加裁决与必查,不复述)
- 严重级:本轮哪些算「阻塞」、哪些「不阻塞、折进③或走微改通道」、哪些「记账不做」(待填)
- 欠账必读:(flow-dispatch 生成;命令行与输出同源;触面参数仓库相对)
- 边界:本轮按类扫的范围是 <哪些文件 / 目录>;类的枚举命令 = <命令>(给枚举命令,不给实例清单)(待填)
- 三改轮:另起 agent;审查方结论优先,反证必须带命令
- 读取纪律 · 工具纪律 · 证据源封闭 · 回件边写边落:(flow-dispatch 各印一行)
- 步骤账(只 ①写):.steps-①写.md;每完成一步 flow-step done <流程目录> ①写 <N> "<一句>"
```

## 按轮次性质追加的块(用到才抄)

```
## 变异纪律(凡打变异的轮次:②B 与 ④B;①写不打)
config 有 `mutate` 门的仓:变异读数取门(flow-gates 只对实改集打,只在独占轮跑),你只读幸存变异体清单判「漏测 / 等价」,不自设、下面六守卫不适用。没有的仓:
六道守卫必开:① old == new 当场中止 ② 写后比 sha256,没变就中止
③ 备份路径带内容哈希,禁同名覆盖 ④ 变异文件放宿主机 scratchpad(容器内会被重置库清掉)
⑤ old 在文件里必须恰好出现 1 次,否则中止(历史回件里的复现命令会随树漂移)
⑥ 每条开跑前先对冻结件 shasum -c,非 OK 行 > 0 拒跑(变异叠加:前一条没复原干净就跑下一条,读数作废重做)
每条记:break_rc · gate_ran(取不到读数行 ⟹ 读数作废)· 收集 · failed · 红在哪(逐字)· restored_identical · rebuild_rc
复原后要 touch + 重建(集成若走构建产物,否则产物污染下一跑);清产物连增量状态文件一起清

## 扫描纪律(凡要拿「零命中 / 全绿」下结论的轮次)
每一类模式都要非空转:另造的已知阳性上跑同一条,必须出非零,命令经 flow-ev 记账。
阳性不许取自本轮的实例清单。六个假绿轴逐个过:参数 / 模式 / 字形(中文数字)/ 措辞 / 范围(grep 可能遵守 .gitignore)/ 增量状态。

## 写文档 / 注释的轮次
三禁:自指的数 · 出处句 · 全称句。改法只删不写:只许删,不许写替代句;删完不通就整句删。
自证用子序列判据:new ⊂ old ⟹ 新增字符 0(对开工快照取,不对 git diff 取)。

## 并行支(worktree)
gitignore 件手工拷进副本;引证 spec 一律读主树,差异当 finding 报;第二支零 DB 面(禁跑重置库与集成);
硬隔离清单:禁碰 <文件 / 目录>,越界 = 废件;账本归主树支,副本支的账目变更写进移交件;裁决号段分开。

## 审轮丙栏的 patch(② 与 ④ 都适用;照 ②A ‖ ②B 的形制,④A 静态审 · ④B 变异审)
④A:--tree 快照 --db 禁用;逐条验收 + 逐欠账三态表 + 分级,零变异。④B:--tree 活树-独占 --db 独占;复跑关键变异 + 对③〇表里新增 / 改的行段自设变异 + build / 集成,抄「变异纪律」块。
两轴零共享推理,后写的不读先写的;分级取并集,阻塞项各经编排方转达回③,复验归提出那条的轴。
微改通道:丙栏每条必闭附一份可 `git apply` 的 patch(落 `.evidence/<轮名>-micro-<裁决号>.patch`,头一行 `# repro: <命令> → 期望 <读数>`,
正文 `git -c core.quotepath=false diff`)+ ev:<名>。行数与性质不由你估,由编排方 `flow-micro <patch>... --face .face-<写轮名>.txt` 从 patch 量(只数非测试新增行)。
MICRO OK ⟹ 编排方 --apply 落笔 + 复跑你写的复现命令对读数,不回来找你;**没附 patch 的条目一律不算微改**。
④B 在活树上出 patch:改 → `git diff` 出件 → 立刻还原(与变异 harness 同一套备份还原 + 冻结件自检),回件里给还原后的 `shasum -c` 读数;快照轴直接 diff。

## 双模型对照(给某轴换模型前必做一批)
同一份产物再派一个影子 agent(model=候选,回件写 `<轮号>-review-<轴>.<model>.md`,树权限快照、库禁用),与原版零共享;
收工 `flow-review-diff <原版> <影子>`:原版独有为空才许把该轴写进 FLOW_ROLE_MODELS;对照批的 token 由 flow-usage 记进轮数账。

## ①写轮额外交付
〇表(回件首节):每个实改文件 ≥ 1 行,符号 → 文件:行段 → 新增 / 改 / 删 → 对应 REQ → 例外;后面三轮按它跳读,编排方按它派生申报。
账本追写草稿:每条触到的开放欠账一行 —— 标记 · 还 / 追写 / 不动 · 一行证据 ev:<名>。
自报三处最没把握。不跑变异电池(变异归 ②B 与 ④B)。步骤账第 0 步是整体设计,之后按 open REQ 一条一步,每条测绿即 flow-step done。

## ③改轮额外交付
〇表每行挂 finding 编号(反证顶回也占一行,性质写 顶回,带 ev:<名>);只动写权限面内的文件;④A 按表验收、④B 按表自设变异,表外改动判红。
③ 的交付态起点 = ② 后微改通道落笔重打的 .after(编排方待填段写明);只剩生产项。
```

## 派单落文件后的 Agent prompt(三行;编排方零 heredoc,其余全在派单文件里)

```
你是 <批次> 的 <轮名> agent。派单:<流程目录绝对路径>/<轮号>-dispatch.md —— 先整读它,再读工作区 .claude/flow-local.md,然后开工。
(Agent 调用的 model 参数照派单块「轮次 / 模型」行;第一行的批次 + 轮名 + 派单路径是 flow-usage 认会话的依据,别改写)
回件:<流程目录绝对路径>/<N>-<轮名>-handoff.md,模板在派单块末尾的 flow:tpl 段,边写边落;收工只写回件,不跑收工命令,不必回信。
```
