# 派单模板(整块照抄进派单,逐项填空;留空 = 派单不合格)

先跑 `flow-dispatch <任务号> --tree <快照|活树-独占|禁入> --db <独占|只读|禁用> --seq <N> --round <轮名> [--core <核心库写权限>] [--plan <plan 绝对路径>] [--cap-ok <理由>] <触面路径(仓库相对)…> > <流程目录>/<轮号>-dispatch.md`(如 `01-dispatch.md` / `02a-dispatch.md`),Edit 补「(待填)」行;派单 = 这个文件,Agent prompt 只给它的路径(末段三行)。带 --plan 时任务节选同源印进块里,任务书正文不再手抄。下面这块是它输出的骨架。

```
## 〇 · 派单必带块

- 树权限:快照(哈希可证) / 活树-独占 / 禁入      ← 三选一,只读 agent 一律快照
- 库权限:独占 / 只读(不许重置库) / 禁用           ← 三选一;任何时刻只许一个持有者跑重置
- git 权限:零 git 写(HEAD 必须 <hash>);porcelain 起点 <N>,允不允许变大:<是/否>
- 写权限面(正面写,不留空):
    许写:<逐个文件或目录>
    禁写:<逐条写明,别写「其余不许」>
    改轮必答:能不能写核心库?——「只许 shell」或「核心库限 <具体文件 / 性质>」
- 裁决号段:从 N 起(并行支各给段,防撞号;开工先核上一轮最大号 < N)
- 交付态起点:flow_sha256_check <上一轮 .after-*-hashes.txt> → 应 RC=0 / <N> OK(并行面逐文件扣除)
- 严重级:本轮哪些算「阻塞」、哪些「不阻塞、折进③或批到收尾轮」、哪些「记账不做」
- 欠账必读:(flow-dispatch 生成;命令行与输出同源;触面参数仓库相对)
- 边界:本轮按类扫的范围是 <哪些文件 / 目录>;类的枚举命令 = <命令>(给枚举命令,不给实例清单)
- 三改轮:SendMessage 回①写轮本人(断连才起新 agent);审查方结论优先,反证必须带命令
- 回件边写边落:每闭一条 finding 就追加落盘,不许攒到收工一次写
- 读取纪律:上一轮回件首节「改动索引表」→ 按表只读文件区间;整读一个文件要给一行理由;plan 只读节选,账本只读必读段
- 工具纪律:互不依赖的调用放同一条消息并发;多步 shell 合一个 Bash;flow-* 与门的输出落 .evidence/,判读贴末行读数 + RC
- 证据源封闭:树 · 上游 spec · 本批流程目录;会话记录与 tool-results 不是证据源
- 收工件:.after-<轮名>-hashes.txt · .declared-<轮名>.txt(一行一路径,不许散文) · <N>-<轮名>-handoff.md(照 references/handoff-template.md,首节改动索引表)
    自跑 flow-manifest verify(文件参数绝对)拿 RC + 非空转;必须读到 `verify OK` 或 `RED` 字样,FATAL 与没跑一律当红
- 本地规矩:读工作区 .claude/flow-local.md(项目自己的门命令、单点资源、实录)
```

## 按轮次性质追加的块(用到才抄)

```
## 变异纪律(凡打变异的轮次)
五道守卫必开:① old == new 当场中止 ② 写后比 sha256,没变就中止
③ 备份路径带内容哈希,禁同名覆盖 ④ 变异文件放宿主机 scratchpad(容器内会被重置库清掉)
⑤ old 在文件里必须恰好出现 1 次,否则中止(历史回件里的复现命令会随树漂移)
每条记:break_rc · gate_ran(取不到读数行 ⟹ 读数作废)· 收集 · failed · 红在哪(逐字)· restored_identical · rebuild_rc
复原后要 touch + 重建(集成若走构建产物,否则产物污染下一跑);清产物连增量状态文件一起清

## 扫描纪律(凡要拿「零命中 / 全绿」下结论的轮次)
每一类模式都要非空转:另造的已知阳性上跑同一条,必须出非零,命令与输出一并贴。
阳性不许取自本轮的实例清单。六个假绿轴逐个过:参数 / 模式 / 字形(中文数字)/ 措辞 / 范围(grep 可能遵守 .gitignore)/ 增量状态。
贴了 N 行 / 判了 N 行,两数相等。

## 写文档 / 注释的轮次
三禁:自指的数 · 出处句 · 全称句。改法只删不写:只许删,不许写替代句;删完不通就整句删。
自证用子序列判据:new ⊂ old ⟹ 新增字符 0(对开工快照取,不对 git diff 取)。

## 并行支(worktree)
gitignore 件手工拷进副本;引证 spec 一律读主树,差异当 finding 报;第二支零 DB 面(禁跑重置库与集成);
硬隔离清单:禁碰 <文件 / 目录>,越界 = 废件;账本归主树支,副本支的账目变更写进移交件;裁决号段分开。

## ④ 复审两段并行(④A 静态审 · ④B 变异审;照 ②A ‖ ②B 的形制)
④A:--tree 快照 --db 禁用;逐条验收 + 逐欠账三态表 + 分级,零变异。④B:--tree 活树-独占 --db 独占;复跑关键变异 + 对③索引表里新增 / 改的行段自设变异 + build / 集成,抄「变异纪律」块。
两轴零共享推理,后写的不读先写的;分级取并集,阻塞项各经编排方转达回③,复验归提出那条的轴。

## 双模型对照(给某轴换模型前必做一批)
同一份产物再派一个影子 agent(model=候选,回件写 `<轮号>-review-<轴>.<model>.md`,树权限快照、库禁用),与原版零共享;
收工 `flow-review-diff <原版> <影子>`:原版独有为空才许把该轴写进 FLOW_ROLE_MODELS;对照批的 token 由 flow-usage 记进轮数账。

## ①写轮额外交付
改动索引表(回件首节):每个实改文件 ≥ 1 行,符号 → 文件:行段 → 新增 / 改 / 删 → 对应 REQ;后面三轮按它跳读,不整读文件。
账本追写草稿:每条触到的开放欠账一行 —— 标记 · 还 / 追写 / 不动 · 一行证据(命令 + 输出摘录)。
flow-fact-lint verify 新增 RED 零。自报三处最没把握。

## ③改轮额外交付
改动索引表每行挂 finding 编号(反证顶回也占一行,带命令);只动写权限面内的文件;④A 按表验收、④B 按表自设变异,表外改动判红。
```

## 派单落文件后的 Agent prompt(三行;编排方零 heredoc,其余全在派单文件里)

```
你是 <批次> 的 <轮名> agent。派单:<流程目录绝对路径>/<轮号>-dispatch.md —— 先整读它,再读工作区 .claude/flow-local.md,然后开工。
(Agent 调用的 model 参数照派单块「轮次 / 模型」行;第一行的批次 + 轮名 + 派单路径是 flow-usage 认会话的依据,别改写)
回件:<流程目录绝对路径>/<N>-<轮名>-handoff.md,照 flow-kit protocol skill 的 references/handoff-template.md(复审轮用 review-template.md),边写边落。
收工读数(flow-manifest verify 末行 + RC)写在回件末尾;不必回信,编排方读文件。
```
