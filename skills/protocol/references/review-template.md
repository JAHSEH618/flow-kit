# 复审回件模板(整块照抄,逐项填;缺项 = 回件不合格)

②A / ②B / ④A / ④B 都用这份;④A 多一张三态表(落 dotfile,见末节)。回件边写边落。开工先读上一轮回件〇节表,按表跳读;整读一个文件要在甲栏给一行理由;**多条读合进同一个 Bash**。
判据命令一律经 `flow-ev`(派单给了连实参的写法):它落全量、记账;甲栏只留每条一行判词,丙栏每条引 `ev:<名>`。判据要全、话要短。
**首行逐字写成 `# <轮名> 回件 · …`**(轮名取派单「轮次 / 模型」行的字面):`flow-round close` 按它认领,认不出 RED。
**〇 节不许留占位**(被判停也写下当下实况;续轮在原位补全)。**〇 + 丙栏 有字节红线**(`FLOW_DOC_BUDGET_HOTPATH`,close 判):丙栏每条只留判据 + ev 名 + 期望读数 + 严重级 + patch 指针。
审轮零改动,〇 是正面结论不是表;申报与冻结由编排方 `flow-round close` 派生,你不跑收工命令。

```
# <轮名> 回件 · <一句话是哪条轴>

## 〇 · 正面结论
可合并 / 可进合并轮 / 可进收口轮   —— 或 —— 必闭 N 条
每条必闭标严重级:阻塞 / 不阻塞(折进③或走微改通道) / 记账不做
「注释说了假话」默认不阻塞 —— 它不影响任何门,不该单独起一轮

## 甲栏 · 实测过的
→ .evidence/<轮名>-log.tsv(N 条)
- <名>:<一行判词>        ← 每条 flow-ev 一行,不多不少(close 判 判词行数 = log 行数);命令 / RC / 末行 / 路径都在账里,不抄
## 乙栏 · 未验推断(没有 flow-ev 账佐证的,一条都不许当结论用;核不了就写「核不了」)
## 丙栏 · 必闭(每条:判据 · ev:<名>(复现命令的账,那一行就是 oracle,写在改动之前)· 期望读数 · 严重级 · patch 指针)
    patch 落 `<流程目录>/.evidence/<轮名>-micro-<裁决号>.patch`:头一行 `# repro: <命令> → 期望 <读数>`,正文 `git -c core.quotepath=false diff`;件内只留一行指针
    编排方 `flow-micro <patch>... --face .face-<写轮名>.txt` 从 patch 量行数(只数非测试新增行)与性质;MICRO OK ⟹ 编排方落笔 + 复跑复现命令,不回来找你
    —— **没附 patch 的条目一律不算微改**;写不出 patch 本来就说明它不是微改,别硬写
## 丁栏 · CARRY(发现了但按触面纪律没做的;进下批派单前要先对树核)
## 戊栏 · 给 flow-local.md 的新实录(踩到就写)

1. 扫描:每类的非空转读数(阳性另造,不许取本轮实例)+ 交付态命中
2. 计数:凡贴出两个本该相等的数,同一行写出差值并说明为何可接受;差 ≠ 0 未解释 = 红
```

## 三态表的体例(写进 `.verdicts-<轮名>.md`,不写进回件)

| 标记 | 判定 | 证据 | 落点 |
|---|---|---|---|
| #44 | 还 | ev:diff44 → 3;回归位 xxx.test.ts:120 | debts.md #44 段 |
| ㉛ | 追写 | 触发面从 A 变成 A\|B,咬人条件不变 | debts.md ㉛ 段 |
| ㉑ | 不动 | 零 fold.ts 改动(numstat 0) | — |

判定只许三选一:还 / 追写 / 不动;每条触到的开放欠账都要有一行(派单欠账必读段即行集)。
`flow-ledger` 是这张表的**唯一**解析器(判定格实际写作 `**还**`),写完自己先 `flow-ledger apply <表>` dry-run 一遍 —— 喂不进去就是体例错。
为什么搬出回件:表是机器输入不是热路径读物,编排方只读〇节 + 丙栏。

## 复审的专项职责

- **「做不到 / 结构上够不着 / 不可达」型断言**(②A / ④A):必须主动找反例,并把找过的路径逐条列出(直呼导出函数 / 注入端口替身 / 别的调用方 / 别的观测量);推不出反例才判成立,并写明射程限定。
- **④B 对③新写的代码自设变异**:按③〇表的新增 / 改行段逐段打;改轮自造的盲区是这一轮最可能漏的。④A 零变异;两轴后写的不读先写的,分级取并集。每条变异开跑前对冻结件 `shasum -c`,非 OK 行 > 0 拒跑。
- **事实句 == 随行命令,三层**:存在性 · 等价性(独立重跑一道,输出与句里的数逐字对齐)· 相关性(命令的射程覆盖这句的主语)。被数集合 = 该段全部句子。
