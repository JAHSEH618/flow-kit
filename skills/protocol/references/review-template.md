# 复审回件模板(整块照抄,逐项填;缺项 = 回件不合格)

②A / ②B / ④A / ④B 都用这份;④A 多一张三态表(落 dotfile,见末节)。回件边写边落。开工先读上一轮回件首节「改动索引表」,按表跳读;整读一个文件要在甲栏给一行理由;**多条读合进同一个 Bash**(一次响应只发得出一个工具块,批量只能从 shell 里省)。
回件长度就是墙钟:四条复审轴各有 21–34% 的墙钟耗在把这份件打出来上。判据要全、话要短;能落 `.evidence/` 的一律落。

```
## 〇 · 正面结论
可合并 / 可进合并轮 / 可进收口轮   —— 或 —— 必闭 N 条
每条必闭标严重级:阻塞 / 不阻塞(折进③或批到收尾轮) / 记账不做
「注释说了假话」默认不阻塞 —— 它不影响任何门,不该单独起一轮

## 甲栏 · 实测过的(每条带命令 + RC + 末行读数 / 摘录 + .evidence 路径;命令与 RC 同层捕获;全量落 .evidence/ 不截断,件内不贴全量)
## 乙栏 · 未验推断(没有命令佐证的,一条都不许当结论用;核不了就写「核不了」)
## 丙栏 · 必闭(每条带判据 + 复现命令 + 严重级;复现命令带唯一锚)
## 丁栏 · CARRY(发现了但按触面纪律没做的;进下批派单前要先对树核)
## 戊栏 · 给 flow-local.md 的新实录(踩到就写)

## 必答的四组数(缺一即回件不合格)
1. 扫描:每类的非空转读数(阳性另造,不许取本轮实例)+ 交付态命中
2. 逐行判:「贴了 N 行 / 判了 N 行」—— 两数必须相等,不许「输出如下」直接跳结论
3. 计数:凡贴出两个本该相等的数,同一行写出差值并说明为何可接受;差 ≠ 0 未解释 = 红
4. 机械核对各自的 RC:flow-route-debts 按收工实改集复跑 diff 派单必读 · flow-receipts 复跑 diff 覆盖声明 · flow-manifest verify(含非空转实证)

## 逐欠账三态表(④A 必填)—— **表落 `<流程目录>/.verdicts-<轮名>.md`,本件只留这一行**
三态表 N 条(还 a / 追写 b / 不动 c)→ `.verdicts-<轮名>.md`;体例与自检见下节
```

## 三态表的体例(写进 `.verdicts-<轮名>.md`,不写进回件)

| 标记 | 判定 | 证据 | 落点 |
|---|---|---|---|
| #44 | 还 | `git diff … \| grep -c …` → 3;回归位 xxx.test.ts:120 | debts.md #44 段 |
| ㉛ | 追写 | 触发面从 A 变成 A\|B,咬人条件不变 | debts.md ㉛ 段 |
| ㉑ | 不动 | 零 fold.ts 改动(numstat 0) | — |

判定只许三选一:还 / 追写 / 不动;每条触到的开放欠账都要有一行(`flow-route-debts` 按实改集复跑的输出即行集)。
`flow-ledger` 是这张表的**唯一**解析器(判定格实际写作 `**还**`),写完自己先 `flow-ledger apply <表>` dry-run 一遍 —— 喂不进去就是体例错,别让收口那一步才发现(已咬两次)。
为什么搬出回件:表是机器输入不是热路径读物,而编排方只读〇节 + 丙栏。实测它占 ④A 回件的 9%(19 行 / 5.0 KB),dotfile 也不进 `flow-doc-budget` 的顶层 `*.md` 扫描。

## 复审的专项职责

- **「做不到 / 结构上够不着 / 不可达」型断言**(②A / ④A):必须主动找反例,并把找过的路径逐条列出(直呼导出函数 / 注入端口替身 / 别的调用方 / 别的观测量);推不出反例才判成立,并写明射程限定(「真库上成立」≠「公开入口上成立」)。
- **④B 对③新写的代码自设变异**:按③索引表的新增 / 改行段逐段打;改轮自造的盲区是这一轮最可能漏的。④A 零变异;两轴后写的不读先写的,分级取并集。
- **事实句 == 随行命令,三层**:存在性 · 等价性(独立重跑一道,输出与句里的数逐字对齐)· 相关性(命令的射程覆盖这句的主语)。被数集合 = 该段全部句子。
- **冻结核对由编排方在活树上跑一次**,轮次 agent 的那份是加的不是替的。
